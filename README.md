# Bhaskar Keelu — Professional IT Portfolio

Public portfolio website for Bhaskar Keelu, Technology Lead with 8+ years of experience.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint

This stack was chosen for SEO-friendly rendering, a strong TypeScript workflow, and a modern responsive UI suitable for a public job-search portfolio.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

## Content policy

Site copy is limited to verified professional information. Roles, projects, technologies, dates, metrics, and contact details are not invented. Confidential employer, customer, and infrastructure information is excluded.
